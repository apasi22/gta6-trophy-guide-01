Roadmap to the platinum

Do the stages in order. Stage 1 holds the only trophy that can be missed — finish it before leaving Chapter 1. Everything else can be done after the story. About 200 hours, difficulty 4/10, one playthrough, all 55 trophies offline [1].

    About this guide

    Every trophy shows its official name, description and grade exactly as PlayStation publishes them. Each guide is written in our own words for this entry as numbered steps, and every step names its source beside it, so you can check any specific location or step — a cited guide beats an uncited one, however detailed. Where a trigger is not yet known, the guide says so instead of guessing; where sources disagree, both versions are shown. The guide is a static site: it loads nothing from the network, your progress is saved only in this browser (localStorage), and export/import moves it as a file you own. No Rockstar Games logo, artwork or game screenshot is used anywhere; the look is our own.
